# Customer Check
Dán câu sau vào Antigravity và thay hai đường dẫn.

> Clone https://github.com/gniltommy-glitch/Customer_Simulator.git vào workspace, đọc SKILL.md và chạy toàn bộ quy trình cho APP_URL. Trả báo cáo tiếng Việt kèm bằng chứng và các thay đổi nên ưu tiên.

Cần Python 3 và quyền điều khiển trình duyệt trong Antigravity. Agent thực hiện thao tác trên web. Python tạo danh sách và kiểm tra báo cáo. Mỗi lượt chạy dùng thư mục kết quả riêng.
